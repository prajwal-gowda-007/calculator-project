# Calculator

A calculator built with HTML, CSS, and JavaScript.

## Live Demo

https://prajwal-gowda-007.github.io/calculator-project/

## Features

- Basic arithmetic operations (+, -, ×, ÷)
- Decimal support
- Prevents multiple decimal points
- Display length limiting for large results
- Rounded long decimal values
- Divide-by-zero error handling
- Consecutive operator handling
- Clear and All Clear functionality
- Backspace/Delete support
- Keyboard support

## Keyboard Shortcuts

| Key | Action |
|------|---------|
| 0-9 | Number input |
| . | Decimal point |
| + | Addition |
| - | Subtraction |
| * | Multiplication (×) |
| / | Division (÷) |
| Enter | Equals (=) |
| Backspace | Delete last entered character |
| C | Clear current display |
| Escape | All Clear (AC) |

## Clear vs All Clear

- **C** clears only the current display.
- **Escape (AC)** resets the entire calculator, including stored numbers and operators.
- **Backspace** removes the last entered character.
- **Enter** performs the calculation, the same as pressing the equals button.
